Капсульная кнопка бренда — основной CTA во всех интерфейсах и на слайдах.

```jsx
<Button variant="primary" size="lg">Обсудить проект</Button>
```

Варианты: `primary` (оранжевый фон), `secondary` (контур), `ghost` (текст), `inverse` (белая на оранжевом/фото). Размеры sm/md/lg. На слайдах — только lg.
