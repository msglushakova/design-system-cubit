# Контекст проекта

Бренд: **КУБИТ / CUBIT** (cubit.su), ООО «Кубит», Новокузнецк — ИТ-решения для предприятий промышленности.
Фирменный стиль лежит в этом же проекте: `styles.css` + `tokens/`, ассеты в `assets/`,
компоненты в `components/`, шаблоны слайдов в `slides/`. Полное описание — `readme.md`.

Правила по умолчанию:
- Язык материалов — русский; в русских носителях логотип RU («КУБИТ»).
- Тёмная тема по умолчанию; светлая (`[data-theme="light"]`) — для документов, бланков, отчётов и КП.
- Оранжевый `#F34925` — единственный акцент; не более одного крупного оранжевого пятна на экран.
- **Фиолетовый не используется** (и mesh-паттерны, построенные на нём, — тоже).
- Фирменный паттерн — треугольная сетка (`assets/pattern-triangles-solid.png` / `-outline.png`);
  «волна» (`assets/wave-dark.png` / `wave-light.png`) — фон титулов и обложек.
- Логотип: основные версии — с градиентом, дополнительные — плоские; охранное поле ≈ буква «Т»;
  минимум 15 мм при печати; не деформировать, не вращать, не ставить на неконтрастный фон.
- Шрифт: заголовки — настоящий HeliosExt Bold (`assets/fonts/HeliosExt-Bold.otf`, `--font-display`);
  основной текст — HeliosExtC Regular (`assets/fonts/HeliosExtC-Regular.otf`, `--font-body`);
  Golos Text — только запасной в стеке.
  Аварийный вариант по гайдбуку — Arial. JetBrains Mono — служебные надписи.
- Иерархия текста: заголовок 220–300 %, подзаголовок 150–250 %, текст 100 %, сноска 80–90 %;
  не более 2–3 цветов текста на странице.
- Эмодзи не использовать.
