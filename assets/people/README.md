# Люди: фото и QR для визиток

| Файл | Что | Где использовать |
|---|---|---|
| `glushakova-orange.jpg` | Анастасия Глушакова, фото на оранжевом фоне, 640×640 | тёмная тема КУБИТ |
| `glushakova-light.jpg` | Анастасия Глушакова, фото на светлом фоне, 640×640 | светлая тема КУБИТ, SkillScape |
| `qr-glushakova.svg` | QR-визитка (vCard): имя, должность, телефон, почта | во всех визитках |

Фото пока без ретуши — при замене сохраните имя файла, и все слайды обновятся.

## Как добавить человека

1. Фото: квадрат по плечи, 640×640, JPEG; имя `фамилия-фон.jpg`.
2. QR-визитка — скрипт `tools/make-vcard-qr.py`:
   `python3 tools/make-vcard-qr.py --last Иванов --first Иван --title "Руководитель" --phone +79990000000 --email ivanov@cubit.su --out assets/people/qr-ivanov.svg`
