Карточка на полупрозрачном тёмном фоне с тонкой рамкой, радиус 16px. Основной блок для «проблема → решение» и списков функций.

```jsx
<Card tag="Обратная связь" title="Отзывы не теряются">Все оценки и эссе хранятся в одном месте.</Card>
```

В сетке 2×2 — обычный размер, в сетке из 4 в ряд — `compact`. Текст — одно-два предложения.
