Таблица оценок как в отчёте руководителя: по столбцу на роль оценщика, среднее считается само и выделено бирюзовым.

```jsx
<ScoreTable roles={["Product manager", "Teamlead", "QA"]}
  rows={[{ name: "Анна К.", scores: [82, 88, 80] }, { name: "Мария Л.", scores: [90, 92, 85] }]} />
```

Числа — моноширинные (tabular-nums). Если данные выдуманы, подпишите «Пример экрана для иллюстрации».
