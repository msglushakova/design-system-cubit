# SkillScape — дизайн-система

Визуальный язык продукта **SkillScape** (skillscape.ru): тёмный интерфейс, точечная сетка, бирюзовый акцент и настоящие экраны в рамках. Система собрана по презентации «SkillScape для отделов» и сверена с сайтом (theme-color `#12B886`).

Лежит рядом с дизайн-системой КУБИТ, но от неё не зависит: свои токены, свои ассеты, классы с префиксом `ss-`.

## Индекс

| Путь | Что внутри |
|---|---|
| `styles.css` | Точка входа: подключает все токены и `components.css` |
| `tokens/colors.css` | Палитра, семантические цвета, светлая тема `[data-theme="light"]` |
| `tokens/typography.css` | Кегли для слайда 1600×900 и для интерфейса |
| `tokens/spacing.css` | Шаг 4px, радиусы, поля слайда |
| `tokens/effects.css` | Тени, точечная сетка, свечение, анимация |
| `components.css` | Готовые HTML-классы: кнопки, пилюли, карточки, списки, этапы, рамки скринов, таблица |
| `components/core/` | Те же компоненты на React (`.jsx` + `.d.ts` + `.prompt.md`) |
| `guidelines/` | Карточки-образцы: цвета, шрифт, отступы, фон, логотип |
| `slides/` | 8 шаблонов слайдов 1600×900, включая визитку в тёмной и светлой теме |
| `assets/` | Логотип и знак (SVG), точечная сетка, три демо-скриншота, фото и QR для визиток (`assets/people/`) |

## Как пользоваться

```html
<link rel="stylesheet" href="skillscape/styles.css">
<section class="ss-slide">
  <p class="ss-eyebrow"><b>Грейды</b></p>
  <h2 class="ss-h2">Грейды и <em>карта компетенций</em></h2>
</section>
```

Для новой презентации копируйте шаблон из `slides/` и меняйте только текст и скриншоты.

## Цвет

- Основа — тёмная тема: фон `#1A1B1E`, карточки `#25262B`, линии `#373A40`.
- Акцент один — бирюзовый: `--accent-strong #12B886` для заливок и кнопок, `--accent #20C997` для выделенных слов в заголовке, `--accent-deep #63E6BE` для текста на тёмно-бирюзовой подложке `--accent-soft #0C3B30`.
- Жёлтый `--warning` — только для сроков и предупреждений, голубой `--info` — для справки.
- Не больше трёх цветов текста на экране: `--text-primary`, `--text-secondary`, `--text-muted`.
- Светлая тема — для документов, писем и печати.

## Типографика

- Шрифт системный (San Francisco / Segoe UI / Roboto), как в приложении. Моноширинный — для номеров слайдов, чисел и подписи адреса в рамке скрина.
- Заголовок слайда 58px, жирность 800, трекинг −0.025em. Одно-два ключевых слова выделяются `<em>` бирюзовым.
- Над заголовком — надзаголовок 17px капсом с разрядкой .18em; название раздела в нём — бирюзовое.
- Лид 26px, основной текст 22px, подписи 19px.

## Фон и глубина

- Слайд: точечная сетка с шагом 28px и бирюзовое свечение в правом нижнем углу.
- Обложка и финал (`ss-slide--hero`) — более сильное свечение с двух сторон.
- Тени только у скриншотов и телефона: экраны «висят» над фоном, карточки — плоские.

## Компоненты

| Компонент | Класс | Когда |
|---|---|---|
| Button | `ss-btn` | Призыв к действию; primary — один на экран |
| Pill | `ss-pill` | Статус: Готово / Бета / Скоро / срок |
| Card | `ss-card` | Проблема → решение, функции; сетка 2×2 или 3 в ряд |
| Ticks | `ss-ticks` | 3–5 преимуществ с галочками |
| Callout | `ss-callout` | Один вывод внизу блока |
| CycleSteps | `ss-cycle` | Этапы процесса (ревью, цикл оценки) |
| ShotFrame / PhoneFrame | `ss-shot` / `ss-phone` | Настоящие экраны продукта |
| ScoreTable | `ss-table` | Оценки по ролям и среднее |
| ContactCard | `ss-contact` | Визитка на слайде «Контакты»: фото, контакты, QR-визитка |

## Скриншоты

- Только настоящие экраны и только в рамке окна или телефона.
- Источник — скриншот 2880 px по ширине, обрезанный до нужного блока; JPEG качества 92 без цветовой субдискретизации. Мелкий текст должен читаться на слайде без увеличения.
- В демо-данных название компании клиента заменяется на «SkillScape».
- Если экран нарисован для примера, внизу пишется «Пример экрана для иллюстрации».

## Тон текста

Как на сайте: коротко, прямо, по делу. Заголовок — утверждение о пользе («Весь прогресс на виду»), а не название раздела. Конкретные числа вместо общих слов. Без эмодзи.

## Логотип

Знак — четыре линии роста, верхняя бирюзовая. Рядом — слово «SkillScape» жирным. Знак не перекрашивать, не вращать, не ставить на светлый фон без светлой версии (`skillscape-logo-light.svg`). В материалах для отделов КУБИТ логотип КУБИТ ставится в подвал первого и последнего слайда.
